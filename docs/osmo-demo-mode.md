# Osmo demo mode

Set `NEXT_PUBLIC_OSMO_DEMO=1` in `.env.local` and restart `npm run dev`. Every message then counts as a new day for Osmo's bond, so he moves from stranger to acquaintance (about message 3), friend (about 8) and old friend (about 30) in one sitting. Remove the line for the real pace.

Demo mode saves the inflated counts to the signed-in account permanently, and the bond never goes down, so use a test account.

Ask "how close are we?" or "when did we meet?" to see where the bond stands.
