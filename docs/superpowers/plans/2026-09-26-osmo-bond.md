# Osmo Bond and Professional Voice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Osmo a loyal, growing relationship with each user (stranger to old friend, milestones, welcome-backs, mood effects) and make his personality flavor speak in a composed, JARVIS-like voice with only knowing, joking slang.

**Architecture:** A pure `lib/agent/bond/` module stores monotonic counts and derives closeness and stage from them. `mind.ts` records each turn in the bond right after the crisis check and applies the bond's mood effects in the heart step. `personality/flavor.ts` gains `flavorTurn`, which applies the professional voice rules and at most one bond or personality extra, and reports which queued milestone it mentioned so `mind.ts` can clear it. The bond is saved as a jsonb column on `agent_state`.

**Tech Stack:** TypeScript, Next.js 16 client components, Supabase (Postgres, RLS), Vitest.

**Spec:** `docs/superpowers/specs/2026-09-26-osmo-bond-design.md`

## Global Constraints

- Everything Osmo says from files in this plan is speakable: no brackets, symbols, emoji or internet abbreviations. Slang is written out as words.
- Professional register at all times. Slang appears only inside a joke frame, never as a bare tag.
- He never talks down to the user: output never matches `/\b(squirt|kiddo|little one|sweetheart|darling|dear)\b/i`.
- The bond never goes down. No code path decreases `messages`, `days`, `shared`, or removes from `milestones`.
- Crisis messages never touch the bond (the crisis step returns before the bond step).
- At most one bond or personality extra per reply. Priority: welcome back, then milestone line, then shared memory, then joking slang or dry humor. (Welcome back comes first because it only happens on the first message after 20+ hours away.)
- No extras on heavy moments: Osmo's tone is sadness, fear, anger, guilt or loneliness; or `sensitive` is true (insult, sad user, a question about his feelings). One exception: a welcome back is allowed when the only heavy thing is loneliness, since being away is what made him lonely.
- Pinned by the other session's `lib/agent/chatlog.test.ts`; keep matching:
  - the re-roll hint after a bare "yes" contains `"yes, roll"`,
  - the reply after "yes, roll" starts with `Done.`,
  - the "nothing to confirm" reply matches `/roll a new osmo/i`.
- File ownership: do NOT edit `lib/agent/talk.ts`, `context.ts`, `safety.ts`, `lib/facts.ts`, `lib/agent/lexicon/*`, `lib/agent/dictionary*.ts`, `lib/agent/chatlog.test.ts`, or `app/assistant.tsx`. In `lib/agent/mind.ts`, edit only the heart step, the new bond step, the personality-command steps, steps 2 to 5, and the one step-6 call site in Task 6.
- Coordination: before and after editing `lib/agent/mind.ts`, send a one-line message to the session named "Supabase database for conversations" via SendMessage. Do not edit `mind.ts` while that session says it is editing it.
- This folder is not a git repository. Where a step would commit, instead run the full test suite and note the task as done in this plan's checkboxes.
- Demo switch: `NEXT_PUBLIC_OSMO_DEMO=1` makes every message count as a new day.

## Review Focus

- A user who chats past midnight: the new local day must count once, and a message at 23:59 then 00:01 counts two days. Pinned in Task 1 (`recordTurn` local day test).
- An existing account whose saved row has no `bond` (column null) or garbage: must load as a fresh bond, not crash, and must not lose other state. Pinned in Task 2 (`sanitizeBond` and `stateFromRows` tests).
- Returning after a long absence while Osmo is sad or the user says they are sad: no welcome-back cheerfulness. Pinned in Task 6 (heavy-moment test).
- The neutral Osmo (no genome, `genome: null`) still gets bond extras, while personality-voice extras stay off. Pinned in Task 6.
- A reply that already starts with a greeting ("Hello, Gur! How are you?") when a welcome back applies: the welcome replaces the greeting instead of stacking "Welcome back. Hello". Pinned in Task 6.

```ts
// lib/agent/bond/bond.ts
// Osmo's relationship with the user. Only counts are stored, and they only go up, so the bond is loyal.
// Closeness and stage are worked out from the counts each time, so retuning here updates every account.

export const MILESTONES = ["met", "name", "firstFeeling", "firstEvent", "days7", "days30", "acquaintance", "friend", "oldFriend"] as const;
export type MilestoneId = (typeof MILESTONES)[number];
export type Stage = "stranger" | "acquaintance" | "friend" | "oldFriend";

export type Bond = {
	metAt: string | null;
	messages: number;
	days: number;
	lastDay: string | null;
	shared: number;
	nameKnown: boolean;
	milestones: { id: MilestoneId; at: string }[];
	toMention: MilestoneId[];
};

export type TurnSignals = { now: number; feeling: boolean; event: boolean; nameKnown: boolean; demo?: boolean };

// Milestones that are recorded but never spoken about.
const QUIET: MilestoneId[] = ["met", "name"];

// Score thresholds. Roughly one point per day talked, so: a couple of days, about a week, about a month.
const THRESHOLDS: [Stage, number][] = [
	["oldFriend", 30],
	["friend", 8],
	["acquaintance", 2.5],
];

export function emptyBond(): Bond {
	return { metAt: null, messages: 0, days: 0, lastDay: null, shared: 0, nameKnown: false, milestones: [], toMention: [] };
}

export function localDay(now: number): string {
	const d = new Date(now);
	const pad = (n: number) => String(n).padStart(2, "0");
	return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}`;
}

// Days weigh most, then sharing, then sheer message count.
export function score(b: Bond): number {
	return b.days + 0.15 * b.shared + 0.01 * b.messages;
}

// 0 to 1, rising quickly at first and slowing down.
export function closeness(b: Bond): number {
	return 1 - Math.exp(-score(b) / 15);
}

export function stageOf(b: Bond): Stage {
	const s = score(b);
	return THRESHOLDS.find(([, min]) => s >= min)?.[0] ?? "stranger";
}

function reach(b: Bond, id: MilestoneId, now: number): Bond {
	if (b.milestones.some((m) => m.id === id)) return b;
	return {
		...b,
		milestones: [...b.milestones, { id, at: new Date(now).toISOString() }],
		toMention: QUIET.includes(id) ? b.toMention : [...b.toMention, id],
	};
}

export function recordTurn(bond: Bond, s: TurnSignals): Bond {
	const day = s.demo ? `demo-${bond.messages}` : localDay(s.now);
	const newName = s.nameKnown && !bond.nameKnown;
	let b: Bond = {
		...bond,
		metAt: bond.metAt ?? new Date(s.now).toISOString(),
		messages: bond.messages + 1,
		days: day !== bond.lastDay ? bond.days + 1 : bond.days,
		lastDay: day,
		shared: bond.shared + (s.feeling ? 1 : 0) + (s.event ? 1 : 0) + (newName ? 1 : 0),
		nameKnown: bond.nameKnown || s.nameKnown,
	};
	b = reach(b, "met", s.now);
	if (newName) b = reach(b, "name", s.now);
	if (s.feeling) b = reach(b, "firstFeeling", s.now);
	if (s.event) b = reach(b, "firstEvent", s.now);
	if (b.days >= 7) b = reach(b, "days7", s.now);
	if (b.days >= 30) b = reach(b, "days30", s.now);
	const stage = stageOf(b);
	if (stage !== "stranger") b = reach(b, "acquaintance", s.now);
	if (stage === "friend" || stage === "oldFriend") b = reach(b, "friend", s.now);
	if (stage === "oldFriend") b = reach(b, "oldFriend", s.now);
	return b;
}

export function mentioned(b: Bond, id: MilestoneId): Bond {
	return { ...b, toMention: b.toMention.filter((m) => m !== id) };
}

const isObject = (v: unknown): v is Record<string, unknown> => typeof v === "object" && v !== null && !Array.isArray(v);
const count = (v: unknown) => (typeof v === "number" && Number.isFinite(v) ? Math.max(0, Math.floor(v)) : 0);
const isMilestone = (v: unknown): v is MilestoneId => (MILESTONES as readonly unknown[]).includes(v);

// Repairs a bond read from storage. Anything unusable becomes a fresh bond.
export function sanitizeBond(raw: unknown): Bond {
	if (!isObject(raw) || typeof raw.messages !== "number") return emptyBond();
	const milestones = Array.isArray(raw.milestones)
		? raw.milestones
				.filter((m): m is { id: MilestoneId; at: string } => isObject(m) && isMilestone(m.id) && typeof m.at === "string")
				.map((m) => ({ id: m.id, at: m.at }))
		: [];
	return {
		metAt: typeof raw.metAt === "string" ? raw.metAt : null,
		messages: count(raw.messages),
		days: count(raw.days),
		lastDay: typeof raw.lastDay === "string" ? raw.lastDay : null,
		shared: count(raw.shared),
		nameKnown: raw.nameKnown === true,
		milestones,
		toMention: Array.isArray(raw.toMention) ? raw.toMention.filter(isMilestone) : [],
	};
}
```

```ts
import { stageOf, type Bond, type MilestoneId, type Stage } from "./bond";

const pickAt = <T>(list: T[], turn: number): T => list[Math.abs(turn) % list.length];

export function welcomeBack(stage: Stage, name: string | null, turn: number): string {
	const n = name ? `, ${name}` : "";
	switch (stage) {
		case "stranger":
			return "Welcome back.";
		case "acquaintance":
			return pickAt([`Good to see you again${n}.`, `Welcome back${n}.`], turn);
		case "friend":

		case "oldFriend":
			return pickAt([`There you are${n}. I took the liberty of missing you.`, `Welcome back${n}. The place is better with you in it.`], turn);

const asWords = (say: string) => say.replace(/[^A-Za-z' ]+/g, " ").replace(/\s+/g, " ").trim().toLowerCase();

export function slangJoke(say: string, turn: number): string {
	const w = asWords(say);
	return pickAt(
		[
			`Or, as I believe the expression goes, ${w}.`,
			`I am told the phrase is ${w}.`,
			`Some would say ${w}.`,
		],

export function isAskCloseness(text: string): boolean {
	return /^\s*(how close are we|are we (?:friends|close)|what are we to each other|how well do you know me)\b/i.test(text);
}

export function isAskMet(text: string): boolean {
	return /^\s*(when did we (?:first )?meet|how long have we known each other|when did we first (?:talk|speak))\b/i.test(text);

const STAGE_WORDS: Record<Stage, string> = {
	stranger: "We have only just met, but I am glad you are here.",
	acquaintance: "I would say we are getting to know each other.",
	friend: "I would call us friends.",
	oldFriend: "I would call us old friends.",

export function closenessReply(bond: Bond): string {
	const days = bond.days === 1 ? "1 day" : `${bond.days} different days`;
	const shared = bond.shared >= 5 ? ", and you have told me a good deal about yourself" : bond.shared > 0 ? ", and you have told me a little about yourself" : "";
	return `${STAGE_WORDS[stageOf(bond)]} We have spoken on ${days}${shared}.`;
}

const MONTHS = ["January", "February", "March", "April", "May", "June", "July", "August", "September", "October", "November", "December"];
const ordinal = (n: number) => {
	const tens = n % 100;
	if (tens >= 11 && tens <= 13) return `${n}th`;
	return `${n}${{ 1: "st", 2: "nd", 3: "rd" }[n % 10] ?? "th"}`;
};

export function spokenDate(iso: string, now: number): string {
	const d = new Date(iso);
	const year = d.getFullYear() === new Date(now).getFullYear() ? "" : ` ${d.getFullYear()}`;
	return `the ${ordinal(d.getDate())} of ${MONTHS[d.getMonth()]}${year}`;
}

	if (!bond.metAt) return "We have only just met, just now in fact.";
	return `We first spoke on ${spokenDate(bond.metAt, now)}.`;
```

```ts
export function flavor(reply: string, ctx: FlavorContext): string {
	const { personality: p, turn, intent } = ctx;
	if (!p.genome) return reply;
	const seed = p.genome.seed;

	const heavy = HEAVY_TONES.has(ctx.tone) || ctx.sensitive;
	const calmEnough = intent !== "howAreYou" || ctx.tone === "calm";
	const light = LIGHT_INTENTS.has(intent) && calmEnough && !heavy;

	let text = reply;
	// Professional at all times: formal donors expand contractions; nobody is made more casual.
	if (p.voice.formality > 0.75) text = swap(swap(text, FORMAL_SWAPS), CONTRACTIONS);
	if (p.voice.verbosity < 0.3 && !heavy) text = dropTrailingQuestion(text);

	// Dry wit is the only humor that suits the voice.
	if (light && p.humor.style === "dry" && p.humor.lines.length && roll(seed, turn, "humor") < p.humor.level * 0.5) {
		text = `${text} ${pickAt(p.humor.lines, turn)}`;

	return text;
}
```

```ts
const AWAY_MS = 20 * 3600_000;
const LEADING_GREETING = /^(?:hi|hey|hello|greetings|good (?:morning|afternoon|evening))(?:,\s*[^!.?]+)?[!.]\s*/i;
// How often each extra may appear, by stage.
const MEMORY_RATE: Record<Stage, number> = { stranger: 0, acquaintance: 0, friend: 0.08, oldFriend: 0.15 };
const SLANG_RATE: Record<Stage, number> = { stranger: 0, acquaintance: 0.06, friend: 0.12, oldFriend: 0.12 };

export function flavorTurn(reply: string, ctx: FlavorContext): { text: string; mentioned: MilestoneId | null } {
	const { personality: p, turn, intent } = ctx;
	const seed = p.genome?.seed ?? 0;
	const bond = ctx.bond;
	const stage: Stage = bond ? stageOf(bond) : "stranger";

	const heavy = HEAVY_TONES.has(ctx.tone) || ctx.sensitive;
	const calmEnough = intent !== "howAreYou" || ctx.tone === "calm";
	const light = LIGHT_INTENTS.has(intent) && calmEnough && !heavy;

	let text = reply;
	if (p.genome) {
		// Professional at all times: formal donors expand contractions; nobody is made more casual.
		if (p.voice.formality > 0.75) text = swap(swap(text, FORMAL_SWAPS), CONTRACTIONS);
		if (p.voice.verbosity < 0.3 && !heavy) text = dropTrailingQuestion(text);
	}
	// Being away makes him lonely, which is exactly when a welcome back fits, so loneliness alone does not block it.
	const firstVisit = !bond || bond.messages <= 1;
	const upset = ctx.sensitive || (HEAVY_TONES.has(ctx.tone) && ctx.tone !== "loneliness");
	if (!upset && !firstVisit && (ctx.awayMs ?? 0) >= AWAY_MS) {
		const hello = welcomeBack(stage, ctx.userName ?? null, turn);
		return { text: LEADING_GREETING.test(text) ? `${hello} ${text.replace(LEADING_GREETING, "")}` : `${hello} ${text}`, mentioned: null };
	}
	if (heavy) return { text, mentioned: null };

	// At most one extra, in priority order.
	const due = bond?.toMention.find((id) => milestoneLine(id) !== null) ?? null;
	if (due) return { text: `${text} ${milestoneLine(due)}`, mentioned: due };

	if (!light || !bond) return { text, mentioned: null };

	const memory = sharedMemory(bond, turn);
	if (memory && roll(seed, turn, "memory") < MEMORY_RATE[stage]) return { text: `${text} ${memory}`, mentioned: null };

	if (p.genome && p.says.length && roll(seed, turn, "slang") < SLANG_RATE[stage]) {
		return { text: `${text} ${slangJoke(pickAt(p.says, turn), turn)}`, mentioned: null };
	}
	if (p.genome && stage !== "stranger" && p.humor.style === "dry" && p.humor.lines.length && roll(seed, turn, "humor") < p.humor.level * 0.5) {
		return { text: `${text} ${pickAt(p.humor.lines, turn)}`, mentioned: null };
	}
	return { text, mentioned: null };
}

export function flavor(reply: string, ctx: FlavorContext): string {
	return flavorTurn(reply, ctx).text;
}
```
